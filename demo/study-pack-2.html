    문제 1 / 3

    X ~ N(μ, σ²) 를 표준정규분포로 바꾸는 식은?

    Z = (X - μ) / σ 이다.

    표준화한 뒤 표준정규분포표를 읽는다.

    표준화: Z = (X - μ) / σ.

    문제 2 / 3

    X ~ N(100, 15²) 일 때 P(X ≥ 115)는 약 얼마인가?

    약 0.1587 (약 16%)이다.

    Z = 1 이고 P(Z ≤ 1) = 0.8413 이므로 1 - 0.8413 = 0.1587.

    P(Z ≤ 1) ≈ 0.8413.
